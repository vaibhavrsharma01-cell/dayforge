# DayForge — Forge Your Perfect Day ⚒

> **"You don't find a great day — you forge it."**  
> A minimalist personal productivity & habit-forming web application built for the relentless.

[![Live App](https://img.shields.io/badge/Live%20Demo-Netlify-00C7B7?style=flat&logo=netlify)](https://dayforgebyautomatex.netlify.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-gold.svg)](LICENSE)

---

## ✦ Key Features

- **Daily Habit Tracking**: Create custom rituals, assign intuitive emoji tags, schedule by time of day (*Morning, Midday, Afternoon, Evening, Night, Anytime*), and check off habits with instant visual feedback.
- **Dynamic Daily Score**: Automated completion rate calculation (`0%` to `100%`) paired with real-time verdicts (*Just Starting*, *Solid Progress*, *Exceptional*, *Perfect Day*) and glowing progress rings.
- **Momentum Streak Engine**: Tracks consecutive disciplined days to encourage habit retention and celebrate consistency.
- **7-Day Ring Matrix & 30-Day Trends**: Visual analytics reflecting weekly completion percentages, historical calendar logs, and a leaderboard of highest-performing habits.
- **Reflection Journal**: Integrated per-day notes and reflections saved alongside daily checklists.
- **Wisdom Sparks**: Curated library of 30+ philosophical quotes across 8 categories (*Habits, Action, Consistency, Discipline, Purpose, Health, Growth, Mindset*) with favorite saving.
- **Client-Side Privacy & Zero Account Friction**: 100% browser-persisted state using `localStorage` — no login, no tracking, and zero latency.
